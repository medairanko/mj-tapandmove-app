# MJ tap&move

Home Assistant پنل هوشمند مزرعه‌ی چون‌آن (천안) را در قالب یک اپ Android تمام‌صفحه نمایش می‌دهد — بدون نوار مرورگر، بدون نیاز به لاگین مکرر.

Android 앱으로 천안 농장의 Home Assistant 스마트 패널을 전체화면으로 보여줍니다 — 브라우저 주소창 없이, 매번 로그인할 필요 없이.

---

## 📲 نصب (فارسی)

1. به بخش **[Releases](../../releases)** همین ریپازیتوری بروید و آخرین نسخه (`v1.0.0`) را باز کنید.
2. فایل `MJ-tapandmove-v1.0.0.apk` را روی گوشی اندروید دانلود کنید.
3. چون این اپ از گوگل‌پلی نیست، اندروید هشدار «منبع ناشناس» می‌دهد — اجازه‌ی نصب را بدهید:
   - `تنظیمات → امنیت (Security) → نصب از منابع ناشناس` را برای مرورگر/فایل‌منیجری که با آن دانلود کردید فعال کنید (متن دقیق بسته به نسخه‌ی اندروید کمی فرق دارد).
4. روی فایل APK دانلودشده بزنید → **Install**.
5. بعد از نصب، آیکن سبز MJ tap&move روی صفحه‌ی اصلی گوشی ظاهر می‌شود.

## ▶️ نحوه‌ی استفاده (فارسی)

1. اپ را باز کنید — یک صفحه‌ی ورود می‌بینید (لوگوی 🏠 روی پس‌زمینه‌ی سبز).
2. **آدرس سرور** را وارد کنید (مثل `farm.mjsmart.co.kr`).
3. فیلد **Token** اختیاری است — می‌توانید خالی بگذارید.
4. روی دکمه‌ی سبز **اتصال** بزنید.
5. اگر توکن نداده باشید، صفحه‌ی لاگین معمولی Home Assistant داخل همان اپ باز می‌شود — یک‌بار با نام‌کاربری/رمز وارد شوید؛ اپ این ورود را برای دفعات بعد به‌خاطر می‌سپارد، دیگر لازم نیست دوباره وارد شوید.
6. از این پس، هر بار اپ را باز کنید مستقیم داشبورد تمام‌صفحه را می‌بینید.
7. برای تغییر آدرس سرور یا خروج، گوشه‌ی **بالا-چپ صفحه‌ی داشبورد را حدود ۱٫۵ ثانیه لمس نگه دارید** — یک تأییدیه برای پاک‌کردن اطلاعات ذخیره‌شده و برگشت به صفحه‌ی ورود ظاهر می‌شود.

## 📲 설치 방법 (한국어)

1. 이 저장소의 **[Releases](../../releases)** 페이지로 이동해 최신 버전(`v1.0.0`)을 여세요.
2. `MJ-tapandmove-v1.0.0.apk` 파일을 안드로이드 폰에 다운로드하세요.
3. 구글플레이 앱이 아니므로 "알 수 없는 출처" 경고가 뜹니다 — 설치를 허용해야 합니다:
   - `설정 → 보안 → 알 수 없는 앱 설치` 에서 다운로드에 사용한 브라우저/파일관리자 앱을 허용해 주세요 (안드로이드 버전마다 문구가 조금 다를 수 있습니다).
4. 다운로드한 APK 파일을 눌러 **설치(Install)** 하세요.
5. 설치 후 홈 화면에 초록색 MJ tap&move 아이콘이 생깁니다.

## ▶️ 사용 방법 (한국어)

1. 앱을 여세요 — 로그인 화면이 나타납니다 (초록색 배경에 🏠 로고).
2. **서버 주소**를 입력하세요 (예: `farm.mjsmart.co.kr`).
3. **Token** 칸은 선택사항입니다 — 비워두셔도 됩니다.
4. 초록색 **연결** 버튼을 누르세요.
5. 토큰을 입력하지 않았다면, 같은 화면 안에서 평소 Home Assistant 로그인 화면이 나타납니다 — 아이디/비밀번호로 한 번만 로그인하면 앱이 로그인 상태를 기억하므로 다음부터는 다시 로그인할 필요가 없습니다.
6. 이후부터는 앱을 열 때마다 바로 전체화면 대시보드가 나타납니다.
7. 서버를 변경하거나 로그아웃하려면, 대시보드 화면의 **왼쪽 상단을 약 1.5초간 길게 누르세요** — 저장된 정보를 지우고 로그인 화면으로 돌아갈지 확인하는 창이 뜹니다.

## 🛠 برای توسعه‌دهنده‌ها / For Developers

این اپ با **React Native + Expo (SDK 57)** ساخته شده. برای build گرفتن از سورس یا تغییر کد:

```bash
git clone https://github.com/medairanko/mj-tapandmove-app.git
cd mj-tapandmove-app
npm install
npx expo start          # تست محلی با Expo Go
```

### ساخت APK جدید

```bash
npm install -g eas-cli
eas login
eas build --platform android --profile preview
```

جزئیات کامل ساختار پروژه، توضیح فیلد Token، و دلیل long-press گوشه‌ی صفحه، در تاریخچه‌ی commit ها و کامنت‌های کد موجود است.
